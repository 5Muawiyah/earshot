THIRD-PARTY NOTICES

Earshot itself is licensed under the MIT licence. The Earshot release also
carries software that was not written for Earshot and is not covered by
Earshot's licence. Each piece is listed below with its publisher, the name of
its licence and where its terms can be read. No licence text is reproduced in
this file. Every file listed is shipped exactly as its publisher built it. The
exact version of each package in a given release is recorded in
Earshot.deps.json, beside Earshot.exe.

The licence texts themselves travel with the release, in the licences folder
beside Earshot.exe, one folder per package. Each is the file the publisher put
in its own package, copied at publish time and never edited. Earshot's own
licence is there too, at licences\Earshot\LICENSE. The entries below say which
file belongs to which package, and say so plainly where a package ships none.
